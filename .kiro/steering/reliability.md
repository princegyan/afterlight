# Reliability

Synthetic exercise data only. Validate model responses as untrusted input. Fall back visibly when the model fails. Never invent locations, headcounts, or verification. Use a supplied exercise point or unknown. The basemap shows real Seattle geography, while report points, names, and claims remain simulated. Summaries count reports, never unique people inferred from duplicate records. Human review is required. Bound file size and validate PNG/JPEG signatures. Store credentials in server environment variables. Public hosting requires a demo access token and persistent storage.

Test domain boundaries, reviewer provenance, malformed model output, failed connections, concurrency, reset, and the end-to-end review flow. Verify factual accuracy with the chosen live model separately from tests of transport/schema behavior.
